## 1. S1 目标

S1 解决的是组件库进入正式页面迁移前的命名和分层问题。

核心目标：

1. 明确 `Editorial*` 是“复古报刊简报系统”的正式迁移候选。
2. 明确 `Bookish*` 是过渡实现层、辅助装饰层或探索附录，不再承担系统主轴。
3. 让 `/decor-preview` 的阅读顺序从“组件堆叠”变成“规范 -> 正式候选 -> 场景样张 -> 过渡资产 -> 探索附录”。
4. 给后续 S2 基础组件一致性微调留下清晰入口。

---

## 2. 分层结论

### 2.1 正式迁移候选

以下组件进入正式迁移候选池，后续可以在 P4 前按页面逐步替换：

| 组件 | 定位 | 当前结论 |
| --- | --- | --- |
| `EditorialIcon` | 正式图标入口 | 可继续作为高频功能图标入口 |
| `EditorialMasthead` | 报头组件 | 可继续验证 front / section / compact variants |
| `EditorialStateMatrix` | 状态矩阵 | 可作为 S2 状态一致性主样张 |
| `EditorialChatSample` | Chat 场景样张 | 可继续对齐对话与记录子页口径 |
| `EditorialTodaySample` | Today 简报样张 | 可继续验证简报主轴 |
| `EditorialPageReframeSample` | R1-R4 页面重排样张 | 可继续承接正式页迁移前草图 |
| `PaperButton` | 候选按钮风格 | S2 需要统一尺寸、状态和密度 |
| `StatusBadge` | 候选状态徽标 | S2 需要统一语义和显示尺寸 |

### 2.2 过渡资产

以下组件保留，但不直接作为正式页面主入口：

| 组件 | 定位 | 处理方式 |
| --- | --- | --- |
| `BookishIcon` | 自绘图标底层和旧语义图标 | 继续支持 `EditorialIcon`，不扩大正式页面直连 |
| `BookishIconWrapper` | `lucide-react` 适配器 | 只作临时补位 |
| `BookishSymbol` | 几何装饰符号 | 只用于标题点缀、分隔点和轻装饰 |
| `BookishLabel` / `MetaText` / `QuoteBlock` / `SectionHeader` | 排版辅助 | 可在样张保留，正式页迁移前逐个评估 |
| `BookishCard` / `PaperSheet` / `StitchDivider` / `OrnamentDivider` / `BindingDots` | 旧容器与分隔 | 进入过渡资产，避免被误认为正式卡片标准 |

### 2.3 探索附录

以下组件保留在预览页作为探索样本，暂不迁入正式页：

| 组件 | 原因 |
| --- | --- |
| `BookishChip` / `ChipGroup` | 需要评估是否演进为正式 `SegmentedTabs` |
| `BookishCheckbox` / `BookishRadio` / `BookishToggle` | 表单控件还缺少真实设置页语境 |
| `SystemBriefCard` | 组合场景价值存在，但职责与 Today / Actions 仍需拆清 |

## 4. 当前判断

S1 后，预览页已经能回答三个迁移前问题：

1. 哪些组件可以作为正式候选。
2. 哪些组件只是历史或过渡资产。
3. 哪些组件需要在 S2 / S3 继续验证。

这一步没有进入正式页面，也没有替换 `ChatPage`、`JournalPage`、`MyPage` 等真实业务页面，符合 P3.5 的边界。

---

## 5. 遗留给 S2 的问题

S2 进入“基础组件一致性微调”，优先处理：

1. `PaperButton` 的高度、内边距、弱按钮状态。
2. `StatusBadge` 的状态语义、尺寸和在不同样张中的密度。
3. `EditorialStateMatrix` 中正式候选组件与探索控件混排的问题。
4. `ChipGroup` 与正式页面 Tab / segmented control 的边界。
5. 预览页内联样式较多，S2 可逐步沉到 `bookish-decor.css`。
6. 360px 视口下的列表、卡片和按钮行密度。
