## 1. 背景

P7-D 已经在高频生成入口接入用户级软配额，但诊断页仍停留在单一 30 天统计视角：

1. 无法快速切换 1h / 24h / 7d / 30d。
2. 只能看错误聚合，不能看最近失败样本。
3. 前端无法定位最近失败来自哪个 feature、provider、model。

本批目标是先补观测闭环，不引入计费或熔断。

---

## 2. 已完成改动

### 2.1 统计窗口增强

更新文件：

- `apps/edge-worker/src/services/llm-invocations.ts`
- `apps/edge-worker/src/routes/system.ts`

新增支持：

- `window=1h`
- `window=24h`
- `window=7d`
- `window=30d`

兼容保留：

- `days=7`
- `days=30`

返回字段新增：

- `windowLabel`
- `windowHours`

原 `windowDays` 保留，用于兼容旧前端调用。

### 2.2 最近失败样本

统计接口新增 `recentErrors`：

```json
{
  "invocationId": 77,
  "feature": "annual_report_blocks_generation",
  "requestRef": "annual_report:2026",
  "providerName": "deepseek",
  "modelName": "deepseek-v4-pro",
  "status": "error",
  "durationMs": 2100,
  "totalTokens": 120,
  "errorCode": "invalid_model_output",
  "errorMessage": "Annual report output failed validation",
  "createdAt": "2026-04-29 18:52:53"
}
```

安全边界：

1. 不返回 `metadata_json`。
2. 不返回 prompt。
3. 不返回 raw response。
4. 不返回 API Key。
5. `error_message` 来自入库前已脱敏字段，仅用于失败定位。

### 2.3 前端诊断页

更新文件：

- `apps/web/src/pages/SystemDiagnosticsPage.tsx`
- `apps/web/src/styles/diagnostics-page.css`
- `apps/web/src/services/api.ts`

新增：

1. 顶部窗口切换：`1h / 24h / 7d / 30d`。
2. 切换窗口后自动刷新统计。
3. 保留手动刷新按钮。
4. 新增“最近失败样本”区块，展示：
   - feature
   - provider / model
   - createdAt
   - errorCode
   - errorMessage
   - durationMs
   - totalTokens

## 3. 当前边界

1. 本批仍只展示当前用户视角；生产环境继续要求 superuser 权限。
2. 本批没有做成本金额估算，成本估算应进入 P7-G。
3. 本批没有失败样本详情页，只是在诊断页展示最近样本。
4. 本批没有加入重试按钮，避免诊断页直接触发额外 LLM 成本。
