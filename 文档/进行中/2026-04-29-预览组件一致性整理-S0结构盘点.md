## 1. S0 结论

当前 `/decor-preview` 已经具备方向展示能力，但还不是清晰的组件标准页。

主要问题不是组件缺失，而是信息层级混在一起：

1. 规范说明、正式候选组件、场景样张、过渡资产、旧探索组件都在同一长页面中连续排列。
2. `Editorial*` 已经出现，但 `Bookish*` 区块仍占据大量页面空间，容易继续误导主轴。
3. R1-R4 页面重排 v2 样张已经加入，但它和 Chat / Today 样张之间的迁移关系还没有明确标签。
4. 过渡语义图标、辅助几何符号、Lucide 适配器有价值，但应该后移到“资产附录”。
5. 表单控件、旧容器、组合业务模块属于探索资产，不应在正式候选区出现。

建议下一步进入 S1：先做命名与分层整理，把预览页改成“规范 -> 正式候选 -> 场景样张 -> 过渡资产 -> 探索附录”的结构。

## 3. 推荐新顺序

S0 建议将预览页调整为以下顺序：

```text
0. 封面与当前状态
1. 主轴规范
2. 图标零容错规范
3. 命名治理与组件分层

4. 正式候选组件
   4.1 EditorialIcon
   4.2 EditorialMasthead
   4.3 PaperButton
   4.4 StatusBadge
   4.5 状态矩阵

5. 场景样张
   5.1 R1-R4 页面重排 v2
   5.2 Chat 样张
   5.3 Today 样张

6. 过渡资产
   6.1 BookishIcon / BookishSymbol
   6.2 Lucide 适配器
   6.3 排版元素

7. 探索附录
   7.1 容器与分隔
   7.2 表单控件
   7.3 SystemBriefCard
   7.4 设计过程
```

排序理由：

1. 先让用户知道“当前标准是什么”。
2. 再展示“哪些组件可以迁移”。
3. 再展示“真实页面怎么用”。
4. 最后保留历史资产和探索组件，避免误导正式迁移。

## 4. 保留、合并、后移、删除建议

### 4.1 保留

| 区块 | 原因 |
| --- | --- |
| 主轴规范 | 仍是组件系统方向锚点 |
| 图标零容错规范 | 图标质量控制必须保留 |
| P1 正式入口 | 当前最明确的正式组件候选 |
| P2 状态矩阵 | 可作为组件状态标准入口 |
| Chat / Today / R1-R4 样张 | 场景验证必需 |
| 状态指示 | `StatusBadge` 是正式候选 |

### 4.2 合并

| 区块 | 合并方式 |
| --- | --- |
| 命名风险记录 | 合并为“命名治理与组件分层” |
| 过渡语义图标 / 模块标识 / 色调变体 | 合并为“Bookish 过渡图标资产” |
| 交互组件 / 状态指示 / 状态矩阵 | 合并或交叉引用为“基础组件状态标准” |
| 排版元素 / 容器与分隔 | 合并到“过渡资产与探索附录” |

### 4.3 后移

| 区块 | 原因 |
| --- | --- |
| 设计过程 | 对理解历史有帮助，但不应在标准区前面 |
| 辅助几何符号 | 是装饰资产，不是主组件 |
| Lucide 风格适配器 | 临时补位，不应靠前 |
| 表单控件 | 暂无正式迁移目标 |
| SystemBriefCard | 组合实验，不是当前正式页迁移入口 |

### 4.4 暂不删除

S0 不建议删除任何区块。

原因：

1. 当前仍处于组件库探索和收口阶段。
2. 一些旧组件可能作为底层依赖继续存在。
3. 删除会影响后续追溯，S1/S2 完成后再决定归档。

## 5. 当前视觉与交互问题

| 问题 | 影响 | 后续阶段 |
| --- | --- | --- |
| 页面过长且无目录 | 用户难以快速理解当前阶段 | S4 |
| 正式候选和探索资产混排 | 容易误判可迁移组件 | S1 |
| `Bookish*` 展示面积偏大 | 主轴可能回到国风书卷 | S1 |
| 状态矩阵混入表单探索控件 | 正式状态标准不够聚焦 | S2 |
| R1-R4 样张没有“可迁移/待确认”标识 | 后续迁移边界不清 | S3 |
| Chat 样张仍偏“对话简报”，未对齐记录子页 v2 | 和最新 IA 有轻微脱节 | S3 |
| Today 样张与待办边界需要文字说明 | 容易把“行动”误解成待办执行 | S3 |
| 多处 inline style | 后续维护和一致性较差 | S2/S4 |

## 6. 组件迁移初判

### 6.1 可迁移候选

| 组件 | 迁移判断 |
| --- | --- |
| `EditorialIcon` | 可作为正式图标入口 |
| `EditorialMasthead` | 可作为报头候选，但 variants 仍需页面适配 |
| `PaperButton` | 可作为复古报刊风按钮候选 |
| `StatusBadge` | 可作为状态徽标候选 |
| `EditorialPageReframeSample` | 不迁移组件本身，但迁移其结构结论 |

### 6.2 暂缓迁移

| 组件 | 原因 |
| --- | --- |
| `BookishCard` | 旧容器语义偏书卷，正式卡片标准未定 |
| `BookishChip` / `ChipGroup` | 可能被正式 `SegmentedTabs` 替代 |
| `BookishCheckbox` / `BookishRadio` / `BookishToggle` | 当前正式页没有优先迁移需求 |
| `SystemBriefCard` | 场景组合过早，需等正式页布局稳定 |
| `BookishIconWrapper` | 适合作为 lucide 过渡，不作为主入口 |

### 6.3 底层或辅助保留

| 组件 | 用法 |
| --- | --- |
| `BookishIcon` | 作为 `EditorialIcon` 的底层实现 |
| `BookishSymbol` | 作为小型装饰符号 |
| `MetaText` | 可作为 meta 行候选，需后续确认 |
| `QuoteBlock` | 可作为引用文本候选，非当前 P0 |
| `SectionHeader` | 可作为章节标题参考，需和正式页面 `section-header` 体系合并 |
