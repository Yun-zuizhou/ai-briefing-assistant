## 1. 文件定位

本文件承接 P3 阶段，负责建立 Today 简报场景样张，并给出正式页面迁移策略。

P3 仍不直接迁移 `TodayPage`。先在 `/decor-preview` 中完成可审阅样张，确认信息层级、组件组合和移动端可读性后，再进入 P4 正式页面分批迁移。

---

## 2. P3目标

1. 以 Today 当前真实信息架构为基础，制作复古报刊简报样张。
2. 验证 `EditorialMasthead / EditorialIcon / PaperButton / StatusBadge` 在 Today 主功能中的承载能力。
3. 明确正式迁移顺序，避免一次性替换整个 Today 页面。

---

## 3. Today当前结构映射

| 现有模块 | 样张表达 | 迁移建议 |
| --- | --- | --- |
| `Masthead` | `EditorialMasthead front` | P4-1 替换或新增 Today 专用报头 |
| 章节导航 | 小型报刊栏目导航 | P4-1 保留交互逻辑，调整视觉 |
| 今日重点 `TodayLeadCard` | 首条简报主卡 | P4-2 先迁移视觉层，不改数据 |
| `TodayFocusBar` | 三栏摘要统计 | P4-2 迁移为报刊统计条 |
| 值得知道 | 新闻列表 / 摘要卡 | P4-3 分批迁移内容卡 |
| 值得行动 | 行动条目 / 截止信息 | P4-3 保留行动优先级 |
| 因你关注而推荐 | 推荐区 | P4-4 最后迁移 |
| 今日速记 | 输入入口 | P4-4 和 Chat 样张联动 |

---

## 4. 样张范围

P3 样张包含：

1. Today 主报头。
2. 栏目导航：重点、知道、行动、关注、速记。
3. 今日重点主卡。
4. 三栏摘要统计。
5. 值得知道列表。
6. 值得行动列表。
7. 速记入口。

---

## 5. 设计约束

1. Today 是核心简报页，页面主语必须是“简报”，不是传统装饰展示。
2. 首屏优先让用户知道：今天看什么、做什么、为什么重要。
3. 报刊风来自排版和信息秩序，不使用复杂纹样、水墨、插画和拟物纸张。
4. 保持 360-430px 移动端阅读效率。
5. P4 正式迁移时不得改动 Today 数据获取、导航逻辑和 API 契约。

## 7. P4迁移顺序建议

| 阶段 | 范围 | 原则 |
| --- | --- | --- |
| P4-1 | Today 报头与章节导航 | 只替换视觉，不改数据流 |
| P4-2 | 今日重点与摘要统计 | 保持现有 props，替换内部样式结构 |
| P4-3 | 值得知道 / 值得行动卡片 | 先迁移一类卡片，截图确认后再扩展 |
| P4-4 | 推荐区 / 速记入口 | 最后迁移，避免影响主链路 |
