## 2. P2目标

1. 建立基础组件状态矩阵，覆盖默认、选中、禁用、成功、待处理等常用状态。
2. 建立复古报刊简报风 Chat 样张，验证 `EditorialMasthead / EditorialIcon / PaperButton / StatusBadge` 的组合能力。
3. 明确后续迁移 Chat 页时的视觉边界：消息流服务任务执行，不做装饰展示页。

## 4. Chat样张范围

P2 Chat 样张只表达 UI 组合，不接业务状态。

样张包含：

1. 紧凑报头：对话简报。
2. 用户消息：右侧气泡。
3. 系统简报消息：左侧纸张式摘要。
4. 状态标签：已执行 / 待确认。
5. 快捷动作：查看简报、收藏、重新生成。
6. 输入条：搜索/发送图标与轻量输入占位。

---

## 5. 设计约束

1. Chat 是任务执行界面，不做大面积传统装饰。
2. 信息层级优先：用户消息、系统判断、执行结果、后续动作必须清楚。
3. 报头使用 `EditorialMasthead compact` 或 `section`，避免占用过高首屏。
4. 动作图标只使用 `EditorialIcon` 第一批正式图标。
5. 装饰符号只能用于分隔、状态和轻量点缀。
