## 1. 问题判断

S4.5 后页面方向成立，但字体观感仍显得不统一。

原因不是“用了多种字体”，而是字体角色没有明确收束：

1. 中文标题、按钮、标签、列表标题都混用 `Noto Serif SC`。
2. 英文装饰字体 `EB Garamond` 和中文 fallback 经常出现在同一类标签里。
3. 中文小标题和标签存在过多 `letter-spacing`。
4. 字体系统没有表达“标题 / 正文 / 标签 / 英文眉标”四种角色。

---

## 2. 字体角色规范

S4.6 在 `bookish-decor.css` 中增加并执行以下角色：

| 角色 | Token | 用途 |
| --- | --- | --- |
| 中文展示标题 | `--bookish-font-display-cn` | 封面标题、报头主标题、文章型大标题 |
| 中文正文 | `--bookish-font-body-cn` | 正文、说明、普通内容 |
| 中文界面标签 | `--bookish-font-label-cn` | 按钮、Tab、列表标题、区块标签、看板标签 |
| 英文眉标 | `--bookish-font-meta-latin` | `VOL`、`EDITORIAL`、`AI DESK`、编号、英文 meta |

核心原则：

1. 中文正文和界面控件不再使用宋体。
2. 英文眉标可以使用拉丁衬线，但中文标签不再套拉丁字体。
3. 宋体只保留给需要“报刊标题感”的中文展示内容。
4. 中文字距默认收紧，避免“假复古”的松散感。

---

## 3. 本次调整

### 3.1 增加字体角色 token

在 `bookish-decor.css` 中增加：

1. `--bookish-font-display-cn`
2. `--bookish-font-body-cn`
3. `--bookish-font-label-cn`
4. `--bookish-font-meta-latin`

### 3.2 按钮与控件回到黑体角色

调整：

1. `PaperButton`
2. `BookishChip`
3. 区块标题标签
4. 状态矩阵标题
5. 低保真样张中的业务标签

这些都使用 `--bookish-font-label-cn`，避免控件看起来像标题。

### 3.3 中文大标题保留报刊感

保留或改为 `--bookish-font-display-cn`：

1. 封面标题。
2. 报头主标题。
3. Today 重点标题。
4. 低保真样张中的关键大标题。

### 3.4 英文眉标统一走英文角色

调整或保留：

1. `DAILY BRIEFING SYSTEM`
2. `VOL. 04`
3. `AI BRIEFING`
4. `ACTION DESK`
5. `GROWTH REVIEW`
6. 编号与英文 meta

这些使用 `--bookish-font-meta-latin`。

### 3.5 降低中文 letter-spacing

调整：

1. 封面中文标题从 `0.04em` 收到 `0.02em`。
2. 主视觉中文标题从 `0.08em` 收到 `0.03em`。
3. 中文辅助短语取消额外字距。
4. 区块标签取消中文混排字距。

## 4. 当前判断

S4.6 后字体系统更稳定：

1. 中文展示标题、正文、控件、英文眉标分工明确。
2. 按钮和标签不再到处使用宋体。
3. 第一屏不再像“多套字体拼贴”。
4. 仍保留复古报刊气质，但更像有规范的 UI 系统。
