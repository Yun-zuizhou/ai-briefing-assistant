## 1. 问题判断

S4.6 后字体已经收口，但正式候选图标仍存在观感问题：

1. 个别图标路径复杂，24px 下显得拥挤。
2. `briefing`、`bookmark`、`settings` 的语义不够直观。
3. `inbox`、`scroll`、`lantern` 的细节密度偏高，视觉重量不稳定。
4. 参考图标和正式候选图标之间仍有风格差异。

本轮不新增图标数量，只优化正式候选图标的路径质量。

---

## 2. 设计约束

继续遵守既定图标规范：

1. 24x24 画布。
2. 2px 描边。
3. `round` cap / join。
4. `currentColor` 继承颜色。
5. 功能图标不使用填充、渐变、阴影、高光、纹理。
6. 图标语义优先，不为装饰牺牲识别度。

---

## 3. 本次调整

| 图标 | 调整方向 |
| --- | --- |
| `chevron-diamond` | 去掉旋转矩形实现，改为稳定菱形路径，箭头缩短并居中 |
| `lantern` | 减少内部曲线噪声，保留主体、顶部、底部和流苏核心线条 |
| `scroll` | 收窄文字线条，降低左侧卷轴和正文区的拥挤感 |
| `inbox` | 从信封感改成档案收纳盒，强化归档语义 |
| `bell` | 改为轻量灯笼提醒语义，和国风辅助元素形成一致性 |
| `settings` | 从放射状齿轮改为滑杆设置，降低复杂度并提升 24px 可读性 |
| `bookmark` | 改为标准书签轮廓，去掉原来的菱形变体 |
| `briefing` | 从双纸叠加改为单页简报，减少线条重叠 |

---

## 4. 当前判断

本轮后图标更接近“复古报刊简报”主轴：

1. `briefing` 更像简报条目，不再像两张重叠纸。
2. `inbox/archive` 的档案语义更清楚。
3. `settings` 更像 UI 操作图标，不再像装饰星芒。
4. `bell` 保留国风辅助，但不抢简报主轴。
5. 图标整体线条更少，24px 下更稳。
