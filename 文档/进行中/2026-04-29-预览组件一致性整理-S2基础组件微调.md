## 1. S2 目标

S2 的任务不是新增组件，而是把 S1 已经分层的基础组件做一致性收口。

本阶段只处理 `/decor-preview` 和 `components/decor`，不进入正式业务页面迁移。

---

## 2. 本次处理项

### 2.1 `PaperButton`

调整目标：

1. 建立移动端默认触控高度。
2. 统一按钮字重、圆角、行高和内边距。
3. 补充 `focus-visible` 状态。
4. 禁用态不只依赖文字颜色，还补充弱背景。

当前口径：

| 状态 | 用途 |
| --- | --- |
| 默认 | 次要操作 |
| active | 当前主操作或选中操作 |
| muted | 禁用或不可执行 |

### 2.2 `StatusBadge`

调整目标：

1. 去掉规范外绿色状态色。
2. 状态色回到 `#8B5A2B`、`#7A6D60`、`#B89A46` 三组系统色。
3. 统一徽标最小高度、字号、字重、边框和背景透明度。

当前口径：

| tone | 用途 | 视觉语义 |
| --- | --- | --- |
| `pending` | 待处理 / 待生成 / 等待确认 | 金棕提示 |
| `success` | 已完成 / 已归档 / 已摘要 | 棕褐确认 |
| `neutral` | 进行中 / 普通状态 / 非强提示 | 浅棕中性 |

### 2.3 `EditorialStateMatrix`

调整目标：

1. 把正式候选与探索附录拆开。
2. 避免 `BookishChip`、`BookishCheckbox`、`BookishRadio`、`BookishToggle` 被误读为正式迁移标准。
3. 保留探索控件，但明确它们仍需后续页面语境验证。

当前分组：

| 分组 | 组件 |
| --- | --- |
| 正式候选 | `PaperButton`、`StatusBadge`、`EditorialIcon` action |
| 探索附录 | `BookishChip`、`BookishCheckbox`、`BookishRadio`、`BookishToggle` |

### 2.4 探索控件触控与焦点

调整目标：

1. `BookishChip` 补充 `aria-pressed`。
2. `BookishCheckbox` / `BookishRadio` 的可点击容器达到 44px 触控高度。
3. `BookishToggle` 的实际按钮区域达到 44px，轨道保持轻量视觉。
4. 探索控件补充 `focus-visible`，便于后续设置页评估。

---

## 3. 本次没有处理的事项

以下事项后移到 S3 或正式页迁移前：

1. 不新增正式 `SegmentedTabs` 组件。
2. 不把 `BookishChip` 改名或迁入正式候选。
3. 不重构 `BookishCheckbox` / `BookishRadio` 的 DOM 结构。
4. 不迁移正式页面。
5. 不扩大颜色系统。
6. 不引入 Storybook 或外部组件文档工具。

---

## 4. 当前判断

S2 后，基础组件的关键风险下降：

1. 正式候选和探索组件在状态矩阵中不再混在同一层。
2. 按钮、徽标、探索控件的尺寸和焦点状态更接近移动端可用标准。
3. 状态徽标回到了复古报刊简报系统的固定色值范围。

这一步仍然是预览组件一致性整理，不代表正式页面可以直接替换所有组件。
