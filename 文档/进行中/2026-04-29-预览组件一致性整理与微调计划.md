## 1. 任务定位

本计划是正式页面迁移前的组件库整理阶段。

它不负责把组件迁入 `ChatPage`、`ActionsPage`、`GrowthPage`、`MyPage`，而是先把 `/decor-preview` 里的组件、样张、命名、状态、布局密度整理成可迁移标准。

一句话目标：

> 让 `/decor-preview` 从“能看见方向的样张页”变成“正式页面迁移前可以信任的组件标准页”。

---

## 2. 为什么先做这一步

当前预览页已经有：

1. `EditorialIcon`
2. `EditorialMasthead`
3. `EditorialStateMatrix`
4. `EditorialChatSample`
5. `EditorialTodaySample`
6. `EditorialPageReframeSample`
7. 旧的 `Bookish*` 组件

但仍存在迁移风险：

1. `Editorial*` 与 `Bookish*` 的边界不够清楚。
2. 预览页区块顺序偏长，组件标准与历史展示混在一起。
3. 按钮、状态徽标、Tag、列表项、分组标题的密度和命名还未完全统一。
4. 样张组件和基础组件之间的关系还不够明确。
5. 进入正式页面前还缺少明确验收清单。

如果现在直接改正式页面，会把这些问题带入真实页面，造成边迁移边修组件库。

## 3. 目标

### 3.1 产品目标

1. 确认复古报刊简报主轴在真实场景样张中成立。
2. 确认国风元素只作为辅助点缀，不干扰信息结构。
3. 确认页面重排 v2 的四个低保真画板能作为正式页迁移依据。

### 3.2 设计系统目标

1. 明确 `Editorial*` 是正式迁移候选。
2. 明确 `Bookish*` 是过渡层或辅助装饰层。
3. 收口按钮、徽标、Tab、列表项、卡片、报头、图标的使用规则。
4. 给每个可迁移组件补齐用途、状态、禁用场景。

### 3.3 工程目标

1. `/decor-preview` 可滚动、无横向溢出、移动端优先。
2. 组件 TypeScript 类型稳定。
3. 局部 lint 和 `tsc --noEmit` 通过。
4. Playwright 至少验证 360px、390px、1200px 三个视口。
5. 页面运行时无新增组件导致的 console error。

## 4. 边界

### 4.1 本阶段处理

| 范围 | 说明 |
| --- | --- |
| `/decor-preview` 信息结构 | 调整区块顺序、标题、说明、分组 |
| `components/decor` | 整理预览组件、补状态、收束命名 |
| `bookish-decor.css` | 微调密度、间距、响应式、触控尺寸 |
| `EditorialPageReframeSample` | 继续修 v2 低保真画板 |
| 组件可迁移清单 | 标记哪些组件可进正式页，哪些暂留预览 |
| QA 检查 | lint、typecheck、截图、溢出、滚动、a11y 基础检查 |

### 4.2 本阶段不处理

1. 不改正式页面布局。
2. 不替换 `ChatPage`、`ActionsPage`、`GrowthPage`、`MyPage` 的组件。
3. 不改后端 API。
4. 不改数据库、contracts、edge-worker。
5. 不引入新 UI 框架。
6. 不做 Storybook 或外部设计系统工具。
7. 不把 `Bookish*` 全量重命名为 `Editorial*`。
8. 不做高保真正式视觉定稿。

## 5. 组件分层口径

### 5.1 正式迁移候选

| 组件 | 角色 | 本阶段动作 |
| --- | --- | --- |
| `EditorialIcon` | 正式图标入口 | 检查尺寸、语义、使用清单 |
| `EditorialMasthead` | 正式报头候选 | 检查 variants 与真实页适配 |
| `EditorialStateMatrix` | 状态标准样张 | 改成可迁移组件状态表 |
| `EditorialPageReframeSample` | 页面重排低保真样张 | 继续微调密度和结构 |
| `PaperButton` | 候选按钮风格 | 检查尺寸、active、muted、触控 |
| `StatusBadge` | 候选状态徽标 | 检查语义、颜色、状态覆盖 |

### 5.2 过渡或辅助层

| 组件 | 角色 | 本阶段动作 |
| --- | --- | --- |
| `BookishIcon` | 自绘图标底层 | 继续作为 `EditorialIcon` 依赖，不直接扩大正式使用 |
| `BookishSymbol` | 装饰符号 | 只用于标题点缀、分隔点、小型辅助 |
| `BookishCard` | 旧容器 | 暂留预览，不作为正式页面唯一卡片标准 |
| `BookishChip` / `ChipGroup` | 旧标签切换 | 检查是否改造成正式 `SegmentedTabs` 候选 |
| `BookishCheckbox` / `Radio` / `Toggle` | 表单探索 | 保留状态矩阵，暂不迁入正式页 |

### 5.3 场景样张层

| 样张 | 用途 | 本阶段动作 |
| --- | --- | --- |
| `EditorialChatSample` | Chat 组合方向 | 对齐新对话记录 v2 口径 |
| `EditorialTodaySample` | Today 简报方向 | 明确和待办页的信息边界 |
| `EditorialPageReframeSample` | R1-R4 页面重排 | 作为正式页布局迁移前置样张 |

| 过早高保真 | 花时间调装饰，结构还没稳 | 本阶段只做一致性和轻微密度调整 |
| 过度抽组件 | 还没进正式页就抽太多新组件 | 只抽已在多个样张重复出现的模式 |
| 正式页迁移提前介入 | 页面和组件库同时波动 | 本阶段禁止改正式页 |
| `Bookish*` 命名继续误导 | 视觉主轴回到国风书卷 | 预览文案持续强调 `Editorial*` 为正式入口 |

## 10. 完成后进入什么阶段

本计划完成后，进入：

1. 正式页布局安排。
2. 组件替换迁移计划。
3. 回到组件系统 P4。

进入 P4 前，需要产出：

1. 可迁移组件清单。
2. 暂缓迁移组件清单。
3. 四页迁移顺序。
4. 每页首批替换组件。
5. QA 截图与验收记录。
