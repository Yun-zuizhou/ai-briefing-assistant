# 2026-05-01 InterestConfig 关注配置页 UX 规格

## 1. 页面定位

`/interest-config` 是关注配置页。

它不是泛兴趣标签页，也不是收藏夹。它负责告诉系统：

> 以后生成简报时，哪些领域应该优先被追踪、摘要和推荐。

## 2. 所属流程

```text
注册 / 个人中心 / Chat 配置确认
-> 配置关注
-> 简报优先使用关注领域
-> 阅读 / 收藏 / 追问 / 待办
-> 画像和后续推荐继续修正关注
```

首次注册后进入 `/interest-config`；后续也可以通过 Chat 配置链路新增或移除关注。

## 3. 页面职责

职责：

- 建立初始关注领域；
- 让用户理解关注会影响简报；
- 支持读取已有关注；
- 支持保存关注并进入简报；
- 使用足够具体的标签，减少“泛兴趣”导致的推荐漂移。

非职责：

- 不展示每日内容；
- 不展示公共热点榜；
- 不作为收藏管理；
- 不配置通知、AI Provider 或账号。

## 4. 标签设计规则

关注标签要服务“简报能追踪什么”，而不是只表达兴趣偏好。

推荐标签特征：

- 能产生新闻、报道、更新或原文；
- 能进入摘要和后续推荐；
- 用户能判断是否真的关心；
- 不过度抽象。

不推荐：

- `科技前沿` 这种过宽大类；
- `生活品质` 这种难以匹配来源的泛词；
- 太猎奇或太冷门导致长期没有内容的标签；
- 只适合收藏、不适合追踪的标签。

## 5. 当前分组

当前四组：

- 技术与工具：AI 应用、AI 产品、开发工具、数据自动化、开源项目；
- 写作与表达：写作素材、内容创作、语言学习、知识管理、个人叙事；
- 职业与机会：远程工作、求职机会、自由职业、技能成长、行业变化；
- 生活与决策：健康习惯、理财观察、城市生活、阅读书单、心理与效率。

这些分组不是最终知识分类，而是给简报生成提供优先方向。

## 6. 与 Chat 配置链路关系

Chat 可以新增或移除关注，但必须确认后写入。

关系：

- `/interest-config` 适合批量编辑；
- Chat 适合一句话微调；
- `/settings` 只展示配置入口或摘要，不复制关注编辑器。

## 7. 成功状态

保存成功后进入 `/today`，让用户看到关注对简报的影响。

后续更理想的验证入口：

- 保存后在简报顶部显示“已按你的关注生成”；
- 简报关注领域报道能清楚展示命中的关注标签；
- Chat 配置成功后能跳转查看简报变化。

## 8. 后续改进

短期：

- 增加“已选关注摘要”；
- 增加标签上限和下限提示；
- 保存后提示“关注已生效”。

中期：

- 允许用户自定义关注；
- 给每个关注显示最近命中内容数量；
- 根据阅读和收藏行为建议新增或移除关注。
