## 1. 文件定位

本文件承接 P1 阶段，负责建立“正式图标路径”和“报头组件一期”。

P1 不做全页面迁移，只把组件库的正式入口先立住，让后续 Chat / Today 页面迁移有明确可调用对象。

---

## 2. P1目标

1. 新增 `EditorialIcon` 作为正式功能图标入口。
2. 新增 `EditorialMasthead` 作为复古报刊简报报头组件一期。
3. 保留 `Bookish*` 作为过渡实现层，不在 P1 直接删除或大规模重命名。
4. 在 `/decor-preview` 增加 P1 样张，展示正式命名、图标清单和报头 variants。

---

## 3. 命名决策

### 3.1 正式入口

P1 起，正式页面优先使用：

| 类型 | 正式入口 | 说明 |
| --- | --- | --- |
| 功能图标 | `EditorialIcon` | 面向业务语义，服务简报、Chat、Today 等正式页面 |
| 报头组件 | `EditorialMasthead` | 承载复古报刊式页眉、模块头和简报头 |

### 3.2 过渡入口

`BookishIcon`、`BookishSymbol`、`SectionHeader` 等组件暂不删除。

处理原则：

1. 已存在页面或预览样张继续可用。
2. P1 后新做的简报主流程组件优先调用 `Editorial*`。
3. `Bookish*` 逐步降级为辅助装饰层或内部实现层。

## 4. 图标系统一期

### 4.1 第一批正式图标

| 图标名 | 语义 | 用途 |
| --- | --- | --- |
| `briefing` | 简报 | Today、简报条目、概览入口 |
| `inbox` | 收件 / 归档 | 收藏、归档、收件箱 |
| `chevron-diamond` | 进入 | 展开、下一步 |
| `search` | 搜索 | 搜索输入、筛选入口 |
| `refresh` | 刷新 | 重试、更新 |
| `bookmark` | 收藏 | 内容沉淀 |
| `send` | 发送 | Chat 输入 |
| `archive` | 归档 | 会话或内容归档 |
| `bell` | 提醒 | 通知、节点 |
| `settings` | 设置 | 系统设置 |
| `close` | 关闭 | 弹窗、取消 |
| `arrow-left` | 返回 | 二级页返回 |

### 4.2 强制规范

1. `24x24` 标准画布。
2. `2px` 单线描边。
3. `round cap / round join`。
4. 功能图标默认不填充。
5. 主线色使用 `#8B5A2B`，通过 token 继承。
6. 图标组件使用固定名称清单，禁止页面随意引入散落 SVG。

## 5. 报头系统一期

### 5.1 组件

新增 `EditorialMasthead`，支持三个变体：

| 变体 | 用途 | 说明 |
| --- | --- | --- |
| `front` | 页面第一屏 / Today 简报主头 | 标题最大，具备期号、日期和说明文本 |
| `section` | 模块标题 | 用于 Chat 样张、简报模块、列表分区 |
| `compact` | 紧凑头部 | 用于小卡片、侧栏、弹层顶部 |

### 5.2 设计约束

1. 报刊感来自版式：细线、meta、刊头、栏目标识。
2. 国风元素只作为两侧小菱形或星点，不作为主体。
3. 不使用复杂纹样、水墨、插画、渐变、阴影和拟物纸纹。
4. 移动端宽度优先，标题不得撑破 360px 视口。
