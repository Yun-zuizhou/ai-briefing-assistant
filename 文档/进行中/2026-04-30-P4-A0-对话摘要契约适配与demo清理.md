## 1. 为什么当前切到这条主线

P4 目标是 `/decor-preview` 已通过 S5 的复古报刊简报组件分批迁入正式页面。但启动 P4-A（对话页记录子页迁移）之前存在阻塞：

1. **ChatRecordsPanel 仍消费 `notes + actions`**，而非摘要任务与会话摘要
2. **`apiService` 没有系统摘要任务方法**（`createSummaryTask` / `getSummaryTaskResult` 等）
3. **Edge Worker 已有 `/api/v1/system/summary-tasks` 链路**，但前端缺乏消费契约
4. **`apps/web/demo/`（8.1MB）是早期探索副本**，与正式 app 重复且已停滞，不清理会持续混淆

结论：不能直接迁移页面视觉，必须先补一个薄契约适配层。同步删除 demo 负资产。

## 2. 当前真实现状

### 负资产

## 5. 状态矩阵（ChatRecordsPanel 摘要 tab）

| 系统状态 | Chat UI 状态 | 处理 |
|----------|-------------|------|
| 无任务 | 未生成 | 显示"生成摘要"按钮 |
| `pending_provider` | 待配置 | 显示"摘要服务未配置"，引导 AI 服务设置 |
| `queued` | 排队中 | 按钮 disabled + "排队中" |
| `running` | 生成中 | `aria-live` 提示 + spinner |
| `succeeded` | 已生成 | 拉取 result 展示摘要 |
| `failed` | 失败 | 显示错误信息 + 重试按钮 |
