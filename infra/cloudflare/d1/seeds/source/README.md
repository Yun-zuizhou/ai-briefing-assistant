# D1 Seed Source

- 当前仓库里的 `seed*.sql` 均由脚本从本地 SQLite / mock 数据生成。
- 生成产物统一输出到 `../generated/`。
- 本目录预留给后续需要长期维护的手写种子或人工校正 SQL。

## 手写演示种子

- `seed.today-briefing-semantic-demo.sql`：简报页语义流演示数据。用于本地 D1，覆盖 `test@example.com` 的关注项、今日内容候选、处理结果、待办候选和 `briefings.payload`。

## 简报演示文案要求

- 首屏摘要负责给出今日编辑视角，建议 120-180 个中文字符：说明共同主线、阅读顺序和为什么值得看。
- 头版卡片负责回答“为什么先看这条”，建议 70-110 个中文字符：不要复述首屏摘要，也不要写成行动计划。
- 关注报道摘要建议 45-75 个中文字符：说明发生了什么，以及它和用户关注方向的关系。
- 后续线索建议 35-60 个中文字符：只提供保存、追问或转待办入口，不抢简报主体。
- 内容详情页可以展开到 120-180 个中文字符：补充背景、影响和核对角度；避免和 AI 摘要、内容摘要逐句重复。
- 文案不应出现“演示内容”“用于承接”“应展示为”等内部说明；演示数据也要像真实可读内容。
